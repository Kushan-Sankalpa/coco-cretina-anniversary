Put your own photos in this folder.

Example:
  public/photos/hero.jpg
  public/photos/date-night.jpg
  public/photos/trip.jpg

Then open src/siteConfig.js and set a memory image like:

image: "/photos/date-night.jpg",

For the hero image, you can replace the placeholder in src/App.jsx with:
<img src="/photos/hero.jpg" alt="Us together" />
